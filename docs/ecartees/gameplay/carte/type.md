# Idées écartées : types de cartes

Idées écartées liées à `gameplay/carte/type.md`.

## 3 types

Écartée le 01/11/2026 : 4 types, à vérifier sur ce que propose Wikipédia.

Par exemple sans type Technique. Plus simple, mais moins de variété.

## 5 ou 6 types

Écartée le 01/11/2026 : 4 types, à vérifier sur ce que propose Wikipédia.

Par exemple en séparant Artefact et Enchantement, ou en ajoutant un type Œuvre. Plus de richesse, plus de règles.

Reprise le 01/11/2026 : 5 types en séparant Objet (artefact) et Savoir (enchantement), voir `gameplay/carte/type.md`. Le type Œuvre reste écarté.

## Œuvres dans le type Technique

Écartée le 01/11/2026 : les œuvres sont laissées de côté pour la première version.

Les films, albums et livres rejoignaient le type des effets permanents, avec les inventions et les outils.

## Œuvres exclues définitivement

Écartée le 01/11/2026 : les œuvres sont laissées de côté pour la première version, pas exclues pour toujours.

Les œuvres étaient retirées de la sélection des articles pour de bon.

## Espèces exclues

Écartée le 01/11/2026 : les espèces sont des Créatures.

Pas d'espèces dans le jeu, ce qui retirait environ 150 000 articles, surtout des ébauches.

## Espèces dans un type à part

Écartée le 01/11/2026 : les espèces sont des Créatures, et il y a 4 types.

Un 5e type pour le vivant non humain.

## Sous-types depuis P31 seul

Écartée le 01/11/2026 : les sous-types viennent de P31 et de P106.

Seulement la nature de l'élément, et les personnes étaient toutes Humain.

## Sous-types choisis par le modèle

Écartée le 01/11/2026 : les sous-types sont calculés par le code depuis Wikidata.

Le modèle choisissait des sous-types dans une liste fermée, comme il choisit les mécaniques.

## Terrains comme ressource, à la Magic

Écartée le 01/11/2026 : le type s'appelle Lieu et la ressource est l'électricité, reçue à chaque tour comme dans Hearthstone.

Les lieux étaient des Terrains qui produisaient le mana. Variantes : Terrains gratuits, un par tour, comme dans Magic, ou Terrains au coût normal qui produisent plus de mana.

## Espèces avec le seul sous-type Taxon

Écartée le 01/11/2026 : on ajoute les rangs de la classification (P171).

Toutes les espèces partageaient le sous-type Taxon. Simple, mais les synergies comme "vos Mammifères" étaient impossibles.

## Un seul type Technique

Écartée le 01/11/2026 : trop large, il mélangeait objets fabriqués, connaissances et logiciels.

Le type Technique couvrait inventions, outils, logiciels et disciplines. Une arme fictive ou un électroscope y côtoyaient les mathématiques.

## Technique limité aux objets, ou limité au savoir

Écartée le 01/11/2026 : on garde objets et savoirs, dans deux types distincts.

Garder 4 types en retirant des cartes soit les objets, soit les connaissances et la technologie, pour l'instant.

## Type le plus prioritaire ou classe directe seulement

Écartée le 01/11/2026 : le type d'un article est celui de la classe racine la plus proche.

Une liste ordonnée de types où le premier qui correspond gagne, ou le test des seules classes `P31` directes avant de remonter la hiérarchie.

## Organisations rangées dans Créature, ou exclues

Écartée le 01/11/2026 : les organisations forment un type Faction.

Les partis, entreprises, clubs et groupes de musique devenaient des Créatures (acteurs collectifs qui se battent) ou restaient hors du jeu pour la première version.


## Sites web exclus, Savoirs ou Factions

Écartée le 01/11/2026 : les sites web, plateformes et réseaux sociaux sont des Lieux virtuels.

Ils étaient exclus en attendant de décider. Autres variantes : des Savoirs comme les logiciels, ou des Factions parce qu'une plateforme rassemble des gens.

## Prix et distinctions exclus, ou rangés dans Savoir

Écartée le 01/11/2026 : les trophées et distinctions (Ballon d'or, Oscar, prix Nobel) sont des Objets.

Les distinctions restaient hors du jeu pour la première version, ou devenaient des Savoirs, des notions abstraites qui agissent sur les autres cartes.
