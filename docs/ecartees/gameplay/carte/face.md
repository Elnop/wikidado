# Idées écartées : face de la carte

Idées écartées liées à `gameplay/carte/face.md`.

## Texte des mécaniques sur la carte, comme Magic

Écartée le 01/11/2026 : une carte a un nombre illimité de mécaniques, leur texte ne tient pas sur la face.

La face affichait les sous-types sur la ligne de type et le texte de chaque mécanique dans une boîte de texte, comme une carte Magic. C'était le format de la première version de la planche d'exemples.

## Icônes de mécaniques sur la carte

Écartée le 01/11/2026 : les mécaniques sont seulement dans la vue détaillée.

Chaque mécanique avait une icône sur la face, avec le texte complet dans la vue détaillée.

## Mécaniques visibles nulle part

Écartée le 01/11/2026 : les mécaniques sont dans la vue détaillée.

Les mécaniques se découvraient en jouant.

## Rareté écrite en toutes lettres

Écartée le 01/11/2026 : la rareté se voit au style de la carte.

Un badge "COMMUNE", "RARE" ou "MYTHIQUE" en haut de la carte.
